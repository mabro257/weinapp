# WineWithFriends

Mobile Web-App (PWA) für einen Freundeskreis: Weine bewerten, Verkostungen festhalten, im Restaurant entscheiden, persönliche Boxplots je Rebsorte.

- **Online bringen:** [ANLEITUNG.md](ANLEITUNG.md)
- **Entscheidungen und Stand:** [PROJEKT.md](PROJEKT.md)
- **Datenbank:** Ordner [`supabase`](supabase), in der Reihenfolge 01, 02, 03 im Supabase SQL Editor ausführen

Ohne Supabase-Zugangsdaten läuft die App im Demo-Modus mit Beispieldaten.
